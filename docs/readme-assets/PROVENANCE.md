# README 插图来源

本目录存放 README 使用的装饰图，均为 AI 生成，不含品牌、商标、可读文字、水印或真实人物。

## 生成信息

- 生成日期：2026-10-16
- 生成方式：Codex 内置 ImageGen（`codex exec`）
- 使用范围：仓库 README 顶部横幅与"为什么开源这个项目"一节
- 后处理：`sips` 裁切到目标尺寸，`cwebp -q 85` 转为 WebP；原始 PNG 不入库

## 素材

- `banner.webp`（1536 × 512）：深蓝到紫色渐变背景，左侧一张无品牌玻璃精华液商品图，经蓝色与金色光轨流向右侧三张竖版短视频分镜。
- `why-lindyson.webp`（1536 × 768）：卖家书桌上用手机拍摄一只无品牌陶瓷杯，商品图经抽象 AI 节点生成三条不同场景的竖版短视频画面。

### banner.webp

> 1536x512 wide hero banner for a GitHub README of an AI e-commerce video generation platform. Flat-modern illustration style, no text, no logos, no watermark, no people.

### why-lindyson.webp

> A clean flat-modern conceptual illustration for the 'why we built this' section of a GitHub README. Left: a small e-commerce seller's desk with a laptop and a single unbranded product (a ceramic mug) being photographed with a phone. Center: the product photo flows through a glowing abstract 'AI' node made of soft layered geometric shapes. Right: three vertical short-video frames showing the same mug in three different scenes (studio, outdoor cafe table, cinematic dark backdrop), with small play icons. Palette: dark navy background, electric blue and warm gold accents, white line details. No text, no letters, no logos, no watermark, no faces.
